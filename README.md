# Frontend Lab

Русскоязычный учебный сайт по JavaScript, TypeScript и React. Включает 48 уроков (по 16 на каждый трек) с теорией, практическими заданиями, подсказками, решениями и проверками результата, а также свободную песочницу.

## Запуск

Требуется Node.js 22.18+ или 24+.

```sh
npm ci
node scripts/build-runtime.mjs
npm run dev
```

Для производственной сборки и локального просмотра:

```sh
npm run build
npm run preview
```

`npm run check` проверяет типы приложения. `npm test` проверяет учебные примеры, решения задач, синтаксические ошибки и защиту циклов. Проверки компилятора выполняются настоящим TypeScript. Тесты React и DOM используют jsdom: проверяют ввод, нажатия, фокус, переключение состояния и асинхронные сценарии без запуска браузера.

## Использование

- Выбери трек или урок в боковом меню. Рекомендуемый порядок: JavaScript → TypeScript → React.
- В редакторе доступны основной файл, CSS и HTML. Для React экспортируй компонент `App` по умолчанию; среда сама отобразит его внутри `#root`.
- Автозапуск обновляет результат через 650 мс после ввода. Ручной запуск: кнопка или Ctrl/⌘ + Enter.
- Во вкладке «Задание» есть условия, подсказка и решение. «Проверить решение» запускает проверки; только успешная проверка отмечает урок пройденным.
- «Песочница» запускает произвольный JS/TS и React TSX. Подключены React 19, React DOM и TypeScript 5.9. Доступны импорты `react`, `react-dom/client` и `react/jsx-runtime`. Сторонние npm-пакеты и сетевые запросы не поддерживаются.
- Код, настройки и прогресс сохраняются в localStorage текущего браузера. В разделе «Мой прогресс» доступны экспорт и импорт резервной копии JSON. Для каждого урока и языка песочницы — отдельный черновик.

## Среда выполнения

Компиляция и проверка типов происходят в Web Worker с локальными декларациями стандартной библиотеки и React. Результат выполняется в `iframe sandbox="allow-scripts"` без доступа к origin родительской страницы. CSP блокирует сетевые запросы. Каждый запуск создаёт новую среду и сбрасывает состояние примера. Сообщения консоли ограничены 200 строками. Циклы инструментируются проверкой бюджета времени (1.5 секунды в рамках одного синхронного блока), чтобы обычный бесконечный цикл не блокировал интерфейс.

Это учебная однофайловая среда, а не полноценный контейнер Node.js: нет файловой системы, установки пакетов или нескольких импортируемых пользовательских модулей. Инструментирование защищает от случайных бесконечных циклов, но не предназначено для выполнения враждебного кода или гарантированного ограничения памяти.

## Материалы

Каждый урок содержит ссылку на первичную документацию: [MDN JavaScript](https://developer.mozilla.org/ru/docs/Web/JavaScript/Guide), [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html), [React Learn](https://react.dev/learn).

Исходники находятся в `src`, учебные материалы — в `src/curriculum.ts` и `src/lessons`, компилятор — в `src/compiler.worker.ts`, исполнитель — в `src/preview.ts`.

## Расширенная программа

- **JavaScript:** деструктуризация, замыкания, reduce и группировка, Set/Map, сортировка, optional chaining, ошибки и JSON, Promise.all; мини-проект расчёта корзины.
- **TypeScript:** keyof и T[K], Record, mapped/conditional types, infer, unknown и type guards, readonly, as const и satisfies; мини-проект типизированной загрузки. Задания проверяют также типовые контракты, а не только результат выполнения.
- **React:** обновление объектов и массивов, useReducer, useRef, Context, собственные хуки, производные данные/useMemo, валидация форм, состояния загрузки; мини-проект списка задач.

Добавление уроков пересчитывает общее количество и процент прохождения. Существующие ID, черновики и отметки завершения сохранены.

## JWT и сессии

Отдельный урок в каждом треке: разбор трёхсегментного JWT в JS, типизированные проверки sub/iss/aud/exp/nbf в TS и учебный интерфейс входа, выхода и истечения в React. Есть пояснения о подписи, допустимых алгоритмах, access/refresh-токенах и хранении сессии.

Декодирование payload и проверка claims не подтверждают подпись. React-пример использует фиктивную сессию и учебные часы, не выдаёт токены и не защищает API. Настоящий API независимо проверяет подпись, ожидаемый алгоритм, издателя, аудиторию, срок действия и разрешения.

Источники: [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519.html), [RFC 8725](https://www.rfc-editor.org/rfc/rfc8725.html), [OWASP JWT Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/JSON_Web_Token_Cheat_Sheet.html).
