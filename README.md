# Frontend Lab

Русскоязычный учебный сайт по JavaScript, TypeScript и React. Включает 18 уроков с теорией, практическими заданиями, подсказками, решениями и проверками результата, а также свободную песочницу.

## Запуск

Требуется Node.js 22.18+ или 24+.

```sh
npm ci
node scripts/build-runtime.mjs
npm run dev
```

Для производственной сборки и локального просмотра:

```sh
npm run build
npm run preview
```

`npm run check` проверяет типы приложения. `npm test` проверяет учебные примеры, решения задач, синтаксические ошибки и защиту циклов. Проверки компилятора выполняются настоящим TypeScript.

## Использование

- Выбери трек или урок в боковом меню. Рекомендуемый порядок: JavaScript → TypeScript → React.
- В редакторе доступны основной файл, CSS и HTML. Для React экспортируй компонент `App` по умолчанию; среда сама отобразит его внутри `#root`.
- Автозапуск обновляет результат через 650 мс после ввода. Ручной запуск: кнопка или Ctrl/⌘ + Enter.
- Во вкладке «Задание» есть условия, подсказка и решение. «Проверить решение» запускает проверки; только успешная проверка отмечает урок пройденным.
- «Песочница» запускает произвольный JS/TS и React TSX. Подключены React 19, React DOM и TypeScript 5.9. Доступны импорты `react`, `react-dom/client` и `react/jsx-runtime`. Сторонние npm-пакеты и сетевые запросы не поддерживаются.
- Код, настройки и прогресс сохраняются в localStorage текущего браузера. В разделе «Мой прогресс» доступны экспорт и импорт резервной копии JSON. Для каждого урока и языка песочницы — отдельный черновик.

## Среда выполнения

Компиляция и проверка типов происходят в Web Worker с локальными декларациями стандартной библиотеки и React. Результат выполняется в `iframe sandbox="allow-scripts"` без доступа к origin родительской страницы. CSP блокирует сетевые запросы. Каждый запуск создаёт новую среду и сбрасывает состояние примера. Сообщения консоли ограничены 200 строками. Циклы инструментируются проверкой бюджета времени (1.5 секунды в рамках одного синхронного блока), чтобы обычный бесконечный цикл не блокировал интерфейс.

Это учебная однофайловая среда, а не полноценный контейнер Node.js: нет файловой системы, установки пакетов или нескольких импортируемых пользовательских модулей. Инструментирование защищает от случайных бесконечных циклов, но не предназначено для выполнения враждебного кода или гарантированного ограничения памяти.
